# Brand

The G.A.W. logo family, exported from the owner's Sketch source (page "Logo"). The Sketch and Figma documents
themselves are not kept here: they hold more than the logo.

Every variant comes twice: `<name>.svg` on the artboard's background, `<name>-transparent.svg` without it.

| File | Variant |
| --- | --- |
| `logo-badge-dark` | Badge, G.A.W. STUDIO |
| `logo-badge-digital-dark` | Badge, G.A.W. DIGITAL — the one the website draws (`packages/gawdigital/src/lib/art/badge.svg`) |
| `logo-badge-reverse-dark` | Badge reversed, G.A.W. GROUP |
| `logo-inverse-dark`, `logo-inverse-light` | Monogram over the wordmark |
| `logo-dark`, `logo-light` | Monogram in a ring |
| `logo-solid-dark`, `logo-solid-light` | Monogram cut out of a disc |
| `logo-old-dark`, `logo-old-light` | The former G.A.W. STUDIO roundel |
| `pin` | Map pin |

The "G.A.W." line is set at 52 pt (the Sketch original had 45 pt), with the dashes shortened to keep their outer
ends and the gap to the text. The website's badge follows the same rule; its colours come from the site's theme.
