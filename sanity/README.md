# Sanity

Reserved for the Sanity content studio of the sites. Nothing lives here yet: the owner creates the Sanity project
first, then the studio is added here as a workspace package and the sites read their content from it.

Until then all copy lives in the translation files of each site (for gawdigital.cz:
`packages/gawdigital/src/lib/translations`).

Project ID, dataset and any API token stay out of the repository; tokens go into Cloudflare secrets.
